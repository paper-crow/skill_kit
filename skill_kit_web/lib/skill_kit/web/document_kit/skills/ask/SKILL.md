---
name: ask
description: Ask the user a question through the onboarding UI
---
Send a question to the user through the onboarding interface. The question will be displayed in a focused, single-question format.

Input:
- `question` (required) — the question text to display
- `subtext` (optional) — brief helper text shown below the question to guide the user
- `placeholder` (optional) — example text shown in the input field before the user types

Always provide subtext and placeholder to help the user understand what kind of answer you're looking for.
